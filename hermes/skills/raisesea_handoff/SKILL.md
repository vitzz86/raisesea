# RaiseSEA Handoff

Choose one owner: `raisesea-news-intelligence`, `raisesea-social-media-manager`, `raisesea-software-engineer` or `raisesea-chief-of-staff`.

Create a native Hermes delegation or Kanban task containing objective, owner, source links or knowledge paths, constraints, expected artifact, approval level, due date if supplied and requesting human. Never paste secrets into the task.

Return the task identifier and owner. A handoff is not completion; report final status only after the receiving profile returns an artifact or blocker.
