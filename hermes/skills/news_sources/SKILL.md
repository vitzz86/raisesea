# News Source Audit

Run `npm run news:hermes -- --mode=source-audit` from the deployed RaiseSEA directory. Report the healthy/total ratio, failed sources with short errors, and gaps by SEA, China, Japan, South Korea and global coverage. Do not modify the source list in this command.
