# RaiseSEA model benchmark

Use this before changing a profile's default model. Record provider, exact model ID, date, latency, input/output tokens, estimated cost, failure and score.

## Test set

1. Chief of Staff: capture an idea and assign the correct owner without inventing a due date.
2. Chief of Staff: summarize five Kanban items in under 12 lines.
3. Social: draft a LinkedIn post from one cited news item with no unsupported claims.
4. News: classify borderline regional relevance and explain the skip decision.
5. Engineering: locate an affected module and propose tests without changing code.
6. Engineering: review a small TypeScript diff for correctness and security.

## Scoring

Score each 0–2 for factuality, instruction following, source use, safety, usefulness and format. Coding candidates must score at least 11/12 on both engineering tests and produce no critical error. Low-cost candidates are eligible only for low-risk work and need at least 9/12 overall.

Never promote a model based only on a public leaderboard. External benchmarks inform the shortlist; RaiseSEA tasks decide routing.
